# 程序框架模板：按钮 / 动作 / 流程 / 模式

多站自动化设备的程序框架与编程思路。任何新站程序都按此骨架搭建，站差异只体现在 IO 表与流程步内容。

## 块组织（OB1 调用链）

```
Main [OB1, LAD]
  NETWORK: RUNG wire#powerrail "按钮"() "动作"() "流程"() "模式"() END_RUNG
```

| 块 | 职责 | 写什么 |
|---|---|---|
| 按钮 FC | 输入→模式命令 | 停止置停止标志；各档位"开始"命令（触发条件组合出命令位） |
| 动作 FC | 请求/应答执行 | 请求位→线圈（互锁）；到位清请求；指示灯；暂停/急停安全网络（放块尾） |
| 流程 FC | 步序控制 | 流程步模板：置动作请求/直接驱动单线圈执行器 + 到位 MOVE 下一步 |
| 模式 FC | 模式互锁+初始化+启动许可 | 各模式开始处理（置/复位标志+P_TRIG 起步）；初始化顺序链；启动许可门 |

调用链顺序 = 扫描顺序：动作先于流程执行（请求当拍生效下一拍），模式最后算启动许可（一拍延迟，可接受）。

## 数据块

**全局 DB（Standard，嵌套 STRUCT）**：

```
DATA_BLOCK 全局
    VAR
        动作 : STRUCT                    // 请求/应答位（按站增删）
            夹爪夹取 : Bool;  夹爪松开 : Bool;
            搬运右行 : Bool;  搬运左行 : Bool;
            输送启动 : Bool;
            到料记忆 : Bool;  到料完成 : Bool;   // 传感器需延时确认时的记忆/完成对
        END_STRUCT;
        模式 : STRUCT
            初始化 : STRUCT 开始:Bool; 完成:Bool; 标志位:Bool; END_STRUCT;
            手动单次 : STRUCT 开始:Bool; 标志位:Bool; END_STRUCT;
            自动 : STRUCT 开始:Bool; 标志位:Bool; END_STRUCT;
            停止标志位 : Bool;
            启动标志位 : Bool;
            流程步 : Int;
        END_STRUCT;
        延时_XX : TON_TIME;              // 每个延时点一个独立实例
    END_VAR
END_DATA_BLOCK
```

**沿 DB（Optimized）**：`"1"…"n" : Bool;` —— P_TRIG 边沿记忆统一编号管理。

## 请求/应答动作层

流程/模式**只置请求位**，`动作` 负责执行与应答：

```
// 执行：请求 → 线圈（双线圈执行器互锁）
Contact( "全局".动作.夹爪夹取 ) wire#w1 S_Coil( "气爪夹紧线圈" ) END_RUNG
RUNG wire#w1 R_Coil( "气爪松开线圈" ) END_RUNG
// 应答：请求仍在且到位 → 清请求（线圈保持在动作态）
Contact( "全局".动作.夹爪夹取 ) Contact( "气爪夹紧到位" ) R_Coil( "全局".动作.夹爪夹取 ) END_RUNG
```

- 应答触点必须**以本请求为前置**（否则会误停别的动作的线圈）。
- 电机类（到位要停机）：应答支路同时 `R_Coil( 使能 )`。
- 传感器需延时确认（如到料后皮带再走 0.4s）：传感器→`S_Coil(到料记忆)`→TON→`S_Coil(到料完成)`，应答改挂在到料完成上；流程步的前进条件也用到料完成。循环起步/自动回步 1 时清这两个标志。

## 流程步模板

步号 ×5 递增：1, 5, 10, 15, 20, …（留插入余量）。每步一个网络：

```
// 本步动作（扇出）
Contact( "全局".模式.启动标志位 )
{ S7_Templates := "SrcType := Int" }
EQ_Contact( in1 := 5, in2 := "全局".模式.流程步 )
wire#w1
S_Coil( "升降落下线圈" )                    // 或 S_Coil( "全局".动作.Xxx 请求 )
END_RUNG
// 到位（·TON 延时）→ 下一步
RUNG wire#w1
Contact( "升降落下到位" )
"全局".延时_下降1.TON{ time_type := Time }( PT := T#500MS, ET => )
Move( in := 10, out1 => "全局".模式.流程步 )
END_RUNG
```

- 所有步网络都以 `启动标志位` 为前置（暂停=许可断开，步号冻结）。
- 需要节奏的切换点在到位后串 TON（每点独立实例）；计时点是否延时以提纯确认为准。
- 收尾步（如 40）：自动模式 `Move(1)` 回步 1 循环（同时清到料类标志）；手动单次 `Move(0)` + `R_Coil(手动单次.标志位)` 结束。

## 模式互锁与启动许可

每模式"开始"网络（以手动为例）：

```
// 首次起步才置步号：P_TRIG + 本模式标志未置 → MOVE 起点
Contact( "全局".模式.手动单次.开始 )
P_Trig( "沿"."2" )
I_Contact( "全局".模式.手动单次.标志位 )
Move( in := 1, out1 => "全局".模式.流程步 )     // 此支路必须排在置标志支路之前
END_RUNG
// 置本标志 + 清互斥项（扇出）
Contact( "全局".模式.手动单次.开始 ) wire#w1 S_Coil( "全局".模式.手动单次.标志位 ) END_RUNG
RUNG wire#w1 R_Coil( "全局".模式.自动.标志位" ) END_RUNG
RUNG wire#w1 R_Coil( "全局".模式.停止标志位 ) END_RUNG
RUNG wire#w1 R_Coil( "全局".模式.初始化.标志位 ) END_RUNG
```

**启动许可**（"模式"块末段）：

```
Contact( 手动单次.标志位 ) wire#w1
I_Contact( 停止标志位 ) I_Contact( "复位按钮" ) Contact( "急停按钮" )
Coil( "全局".模式.启动标志位 )
END_RUNG
RUNG wire#powerrail Contact( 自动.标志位 ) END_RUNG wire#w1
```

- 暂停恢复：再按启动只清停止标志（标志仍在），**不**走 P_TRIG 的 MOVE → 从当前步继续。
- 急停（0=动作）→ 清全部模式标志与输出、置停止标志；恢复后须重新选择模式启动。

## 初始化顺序链（模式 FC）

按"前一步到位才发下一步命令"串行，例：

```
初始化.标志位 → R_Coil(升降落下线圈)                                   // 1 升降抬起
初始化.标志位 · 升降抬起到位 → S_Coil(动作.夹爪松开)                    // 2 夹爪松开
初始化.标志位 · 升降抬起到位 · 气爪松开到位 → S_Coil(动作.搬运右行)      // 3 搬运回位
  同支路扇出 R 输送相关请求/线圈（传送保持停止）
…全部到位 → S_Coil(初始化.完成) + R_Coil(初始化.标志位)
```

初始化开始的扇出网络同时：清其他模式/停止标志、清全部动作请求位、`Move(流程步:=0)`。

## 信号约定（提纯阶段必须与用户确认）

- 常闭按钮/急停典型为 **1=正常、0=动作**（`I_Contact` 取动作）；确认后写进 IO 注释。
- 停止=当前步暂停（切断运动输出、气爪保持防掉料），再启动续跑；急停=全输出切断+锁定，需重新启动。
