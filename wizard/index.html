PLC 设备与网络

可添加多台 PLC；每台设置 PN/IE 接口与 IPv4 地址。TIA 版本为整个项目的目标版本。

项目信息

PLC 设备列表 1 台

多台 PLC 时按住同一子网规划 IP（如 192.168.0.1 / .2 / .3）；PN/IE 接口用于站间通信。

导入 IO 点

支持粘贴文本/表格（地址、符号、说明、状态），自动解析成可编辑点表；图片可一并交给 Agent 识别。

粘贴 IO 表

命名规范：中文、无空格；注释建议「符号 说明：状态语义」

点表 0 点

地址类型变量名(中文)符号注释

设备流程编排

按执行顺序列出动作与完成判据；模式触发写清楚，Agent 会先提纯回来给你确认。

模式与触发

动作序列 0 步

步动作（执行器做什么）完成判据（哪个传感器）延时(ms)

编程语言

选择生成的程序语言；两者都走框架模板（按钮/动作/流程/模式）。
梯形图（LAD）
推荐 · 电工可读 · 触点/线圈/定时器全梯形图
SCL（结构化控制语言）
以 LAD 壳 + SCL 网络混编实现（TIA 导入兼容）

一键生成

仅 PLC 型号必填，其余步骤没填就留空；生成 project.json 交给 Agent 一键生成 TIA 项目。
✓ 配置已生成并下载 project.json。把它放进工作目录，对 Agent 说「按配置生成项目」即可。
